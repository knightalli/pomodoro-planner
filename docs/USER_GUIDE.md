# Тайм-трекер — руководство пользователя

Приложение для Windows: таймер работы с перерывами (в стиле Pomodoro), автоматический ежедневник, напоминания и статистика. Все данные хранятся локально на компьютере.

## Установка и запуск

- Установленное приложение запускается как обычная программа.
- Для запуска из исходников см. `docs/DEV_GUIDE.md`.

## Вкладки

### ⏱ Таймер

Основной экран работы.

1. **Выберите задачу** в выпадающем списке над таймером:
   - «Сегодня по плану» — задачи, которые ежедневник поставил на сегодня (со временем начала);
   - «Остальные задачи» — задачи на другие дни и не влезшие в план (с дедлайном);
   - «— Без задачи —» — свободный трекинг без привязки.
2. Нажмите **▶ Старт**. С выбранной задачей таймер идёт **на обратный отсчёт** — показывает, сколько осталось до её оценки; без задачи — считает время до перерыва.
3. **⏸ Пауза** / **▶ Продолжить** / **⏹ Стоп** — управление сеансом.
4. Под кругом — прогресс выбранной задачи (отработано / оценка) и строка **«☕ Перерыв через …»** — сколько осталось до ближайшего перерыва. На полосе прогресса зелёным отмечены места перерывов внутри задачи.

**Перерывы.** Когда отработанное время достигает «Интервала до перерыва» (по умолчанию 15 мин), звенит колокольчик и начинается перерыв (по умолчанию 5 мин). После перерыва таймер автоматически продолжает работу.

**Завершение задачи.** Когда отработанное по задаче время достигает её оценки, задача отмечается выполненной автоматически (звук + уведомление). Таймер при этом продолжает идти — время сверх оценки тоже записывается.

**📺 Виджет** — маленькое всегда-наверху окошко: обратный отсчёт остатка задачи (или время до перерыва), имя задачи, полоса прогресса и зелёный счётчик «☕ до перерыва». Клик по виджету открывает главное окно, таскание — за любое место.

### 📅 План (ежедневник)

Автоматический планировщик дня.

**Как это работает.** Вы задаёте:
- **границы дня** — в какие часы вообще можно планировать (по умолчанию 08:00–23:00);
- **фиксированные дела** — регулярные занятия с постоянным временем (работа, пары, тренировки) по дням недели;
- **задачи** — с длительностью, приоритетом и дедлайном.

Приложение само раскладывает задачи по свободным «окнам» дня, начиная с ближайшего времени. Чем раньше дедлайн и выше приоритет — тем раньше слот.

**Перерывы в плане.** Перерывы считаются накопительно, как работает таймер: после каждых N минут суммарной работы встаёт перерыв — внутри задачи или между задачами. Задача на 20 мин при 15/5 занимает 25 минут; задача ровно на 15 мин — 20 (перерыв «переходит» следующей задаче). Свободный зазор длиной с перерыв и больше считается отдыхом — счёт начинается заново.

**«Делаю сейчас».** Нажатие ▶ у задачи (или первый тик таймера по выбранной задаче) прибивает её слот к текущему моменту — она поднимается наверх плана, а остальные задачи перепланируются вокруг неё. Пока задача на паузе, её блок растёт вместе с реальным временем и сдвигает дела ниже — план остаётся честным.

**Редактирование.** Кнопка **✎** у задачи (в таймлайне и в блоке «не хватает времени») открывает форму с текущими данными — можно поменять название, длительность, приоритет и дедлайн. Фиксированные дела редактируются так же.

**Просроченные задачи «плывут» вниз.** Задача, которую не начали в своё слот-время, раз в минуту переставляется на ближайшее свободное — план остаётся актуальным. Закреплённый слот держит только активная (выбранная в таймере) задача.

**Не влезло в день?** Задачи, которым не хватило свободного времени до дедлайна, показаны в блоке «⚠ Не хватает свободного времени». Если дедлайн позволяет (завтра и позже), задача сама уезжает на следующий день; для сегодняшнего дедлайна есть кнопка **«→ Завтра»** — переносит дедлайн и задача встаёт в план завтрашнего дня.

**Навигация:** ‹ › переключают день, кнопка «Сегодня» возвращает к текущей дате. Счётчик «Свободно» показывает остаток свободного времени в выбранный день (для сегодня — от текущего момента).

**Фиксированные дела** можно редактировать кнопкой **✎** — форма откроется с текущими данными, «Сохранить» применит изменения (план пересчитается сам).

**Таймлайн** показывает фиксированные дела и задачи по времени. У каждой задачи:
- **▶** — начать трекать её прямо сейчас (выбирает задачу и запускает таймер);
- **✓** — отметить выполненной / вернуть в работу (↺);
- **✕** — удалить;
- полоса прогресса — отработано / запланировано.

**Уведомления о начале.** Когда наступает слот задачи, приходит уведомление «пора начинать» (окно 15 минут).

**«Не хватает свободного времени до дедлайна»** — блок с задачами, которые не влезли в план. Варианты: расширить границы дня, сдвинуть дедлайн (пересоздать задачу), убрать лишние дела или отметить задачу выполненной/удалить.

**Переносы.** Неначатая задача каждый раз перепланируется заново (в т.ч. уедет на завтра, если сегодня места не осталось). Задача, по которой уже шёл трекинг, свой слот сохраняет.

### 📊 Статистика

- Итоги по дням: общее отработанное время и разбивка по задачам.
- Выполненные/пропущенные напоминания за день.
- Хранится история последних ~30 дней. Раз в день (в настраиваемое «время сброса») день закрывается, итоги уходят в историю, а выполненные задачи прошлого дня удаляются.

### 🔔 Напоминания

Два типа:
- **Каждые N минут** — интервальное напоминание (например, «попить воды» каждые 60 мин);
- **В определённое время** — один раз в день в заданное время.

После срабатывания напоминание ждёт подтверждения кнопкой **✓ Подтвердить**. Если не подтвердить, оно повторяется каждую минуту до 3 раз, затем уходит в «Пропущено». Счётчики done/missed видны в статистике.

## Настройки (⚙ на вкладке Таймер)

| Параметр | Что делает |
|---|---|
| Интервал до перерыва | Минут работы до перерыва |
| Длительность перерыва | Минут отдыха |
| Сброс статистики в | Во сколько подводятся итоги дня |
| Начало / конец дня | Рабочее окно для планировщика |
| Автозапуск | Запуск приложения при включении ПК |

Все поля времени в приложении — в 24-часовом формате (выбор часов и минут из списков).

## Где хранятся данные

Всё (задачи, план, таймеры, статистика) — в `localStorage` приложения:
`%APPDATA%\com.pomodoro.app\`. В облако ничего не отправляется.

## FAQ

**Уведомления не приходят?** Проверьте, что Windows не блокирует уведомления приложения (Параметры → Система → Уведомления), и что приложение запущено — напоминания работают только пока оно открыто.

**Задача стоит в прошлом времени в плане?** Планировщик не ставит задачи в уже прошедшее время — для сегодня он ищет слоты только от текущего момента. Если задача «в прошлом», значит по ней уже шёл трекинг — такие слоты сохраняются.

**Перезапустил приложение — таймер пропал?** Состояние (включая идущий таймер) сохраняется постоянно, но отсчёт продолжается только пока приложение запущено.
