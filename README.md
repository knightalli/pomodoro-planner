# Тайм-трекер (Tauri + React + TypeScript)

Приложение с тайм-трекингом, статистикой, напоминаниями и ежедневником.

## Возможности

- ⏱ **Таймер** — трекинг времени по разделам, авто-перерывы, виджет поверх окон.
- 📅 **Ежедневник** — задачи с длительностью, приоритетом и дедлайном расставляются автоматически по свободным слотам дня (учитываются начало/конец дня и фиксированные дела: работа, пары и т.п.). Кнопка ▶ у задачи запускает таймер, отработанное время идёт в прогресс задачи; при наборе запланированной длительности задача отмечается выполненной.
- 📊 **Статистика** — итоги по дням, разделам и напоминаниям.
- 🔔 **Напоминания** — по интервалу или в конкретное время.
