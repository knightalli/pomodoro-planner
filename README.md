# Тайм-трекер (pywebview + React + TypeScript)

Приложение с тайм-трекингом по задачам, статистикой, напоминаниями и ежедневником.
Десктопная оболочка — Python + WebView2 (`app.py`), MSVC/Visual Studio не нужны.

## Запуск

Двойной клик по `run.bat` — сам создаст venv, поставит зависимости и соберёт
фронтенд. Либо вручную:

```bash
npm install && npm run build
python -m venv .venv && .venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python.exe app.py
```

## Возможности

- ⏱ **Таймер** — выбираете задачу из ежедневника и работаете по ней с авто-перерывами; время пишется в прогресс задачи. Виджет поверх окон.
- 📅 **Ежедневник** — задачи с длительностью, приоритетом и дедлайном расставляются автоматически по свободным слотам дня (учитываются границы дня и фиксированные дела: работа, пары и т.п.). При наборе запланированной длительности задача отмечается выполненной.
- 📊 **Статистика** — итоги по дням, задачам и напоминаниям.
- 🔔 **Напоминания** — по интервалу или в конкретное время.
